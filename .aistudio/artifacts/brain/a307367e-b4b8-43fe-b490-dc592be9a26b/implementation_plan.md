# 「我的第一組高爾夫球桿選擇器」實作計畫

為高爾夫新手打造的互動式球桿挑選面試系統。透過 7 道循序漸進的結構化選擇題，結合專業球具物理特性（桿頭構造、鍛造/鑄造、桿身材質與剛性、長度與角傾、品牌譜系與市場流通），即時生成專業分析專文、重點規格速查卡與智慧 Google Shopping 搜尋串接。

---

## 使用者確認事項與關鍵設計決策

> [!IMPORTANT]
> 依據前期 Clarification 確認之設計基準，本專案將嚴格遵循以下決策進行建構：

- **視覺風格確認**：採用**現代果嶺輕奢風**（深森林綠 `#12291E`、暖米白 `#F9F8F5`、霧面象牙金 `#C8A86B`），營造專業、沉穩且具備當代高球球場質感的沉浸氛圍。
- **預算幣別與計價方式**：使用**新台幣 TWD**，提供 10,000 元至 120,000+ 元的平滑數值滑桿，並支援「無上限」一鍵切換模式。
- **結果呈現維度**：產出專文分析、關鍵規格速查卡（桿頭結構、桿身彈性、材質、品牌取向、慣用手配備），以及一鍵複製摘要與直接跳轉 **Google Shopping** 搜尋。

## 1. 產品概述與核心理念

### 產品定位
「我的第一組高爾夫球桿選擇器」旨在消除高爾夫新手在面對琳琅滿目的球桿規格、術語與品牌時的資訊焦慮。不依賴外部 AI API，純粹以高爾夫球具工坊工程邏輯（Clubfitting Rules）為基底，透過靜態純前端演算法，在 2 分鐘內引導使用者找到真正適合自己的第一把/套球桿。

### 目標受眾
- 剛接觸練習場或剛完成新手課程、準備入手第一套球桿的新球友。
- 尋求客觀規格建議、不想在球具店被推銷員強銷高利潤冷門庫存的消費者。
- 有特定身形（如身高過高/過矮）、左手慣用球友或預算考量的球友。

## 2. 使用者體驗與視覺設計

### 使用者互動流程 (User Flow)
```
┌─────────────────┐       ┌──────────────────────┐       ┌────────────────────────┐
│  歡迎與導引首頁 │ ───>  │ 7 道循序漸進問卷步驟 │ ───>  │  綜合診斷與結果儀表板  │
│  介紹與目標設定 │       │ 即時進度與選項動態卡 │       │  規格卡 + 專文 + 搜尋  │
└─────────────────┘       └──────────────────────┘       └────────────────────────┘
```

1. **問卷引導體驗**：
   - 頂部單行導航，具備步驟進度指示與切換題目的平滑過渡。
   - 題目卡片設計符合觸控尺寸（$\ge 48\text{px}$ 點擊區塊），支援鍵盤快捷與行動端滑動。
   - 支援隨時返回修改前題，且狀態完整保留。
2. **7 大題組規格 (依需求精確落實)**：
   - **Q0 購買目標**：鐵桿組 (Iron Set) / 木桿 (Driver/Woods) / 整套 (Full Package Set)
   - **Q1 購買策略**：一次到位 (直上職業級球桿) / 長久使用 (中庸之道，稍進階平衡型) / 循序漸進 (高容錯、易打性優先) / 預算優先 (挑選高CP值組合)
   - **Q2 預算範圍**：新台幣滑桿（$10,000 \sim 120,000$ TWD）+「無上限」切換按鈕
   - **Q3 身高與擊球習慣**：
     - 身高：偏高（男性 >183cm / 女性 >172cm）、一般、偏矮（男性 <170cm / 女性 <158cm）
     - 慣用手：右手 / 左手 (Left-handed)
     - 性別/體能導向：男款 (標準揮重與桿身管徑) / 女款 (輕量化高容錯、L flex)
   - **Q4 二手考量**：願意考慮二手優質桿 / 堅持全新正品
   - **Q5 品牌地域偏好**：歐美系 (TaylorMade, Callaway, Ping, Titleist, PXG 等) / 日系 (Mizuno, XXIO, Srixon, Honma, Yamaha 等) / 其他或綜合評估
   - **Q6 品牌調性取向**：看起來很懂球 (極簡線條、純粹操控) / 帶奢侈品屬性 (尊榮工藝、高質感塗裝) / 第一組練習買最便宜就好 (純實用高CP、耐操)

3. **診斷結果頁面**：
   - **重點規格速查卡 (Spec Summary Cards)**：
     - 建議桿頭型態：超大凹背 (Super Game Improvement) / 寬底凹背 (Game Improvement) / 中空或肌肉刀背 (Muscle Back / Players)
     - 製程與構造：壓鑄鑄造 (Cast) / 軟鐵鍛造 (Forged) / 多材料混合 (Multi-material Hybrid)
     - 桿身規格：碳纖維 (Graphite, 45-65g) / 輕量鋼管 (Lightweight Steel 85-95g) / 重鋼管 (105-125g)
     - 硬度 (Flex)：Ladies (L) / Senior (A) / Regular (R) / Stiff (S) / X-Stiff (X)
     - 桿長與仰角 (Length & Lie)：加長 +0.5"~+1"、標準、或縮短 -0.5"，左手專屬註記
   - **個人化分析專文**：
     - 不列出特定型號，但明確點名推薦品牌光譜與技術選型原因。
     - 二手防踩坑指南（針對勾選二手者）：包括桿面溝槽深淺檢驗、桿身螺紋疲勞、握把硬化及假桿防範技巧。
   - **Google Shopping 智慧搜尋串接**：
     - 精心組裝精準搜尋 Query（例如 `高爾夫 男用 左手 鐵桿組 日系 碳纖維 R 二手` 或 `Golf driver 輕量鋼 S Callaway Ping`）。
     - 提供直接點擊新開視窗搜尋，並提供「複製規格摘要」按鈕，方便存入筆記或傳給店家。

### 資料模型與邏輯推導核心 (`src/lib/fittingEngine.ts`)
- **桿身推導矩陣**：根據性別、年齡/體能策略、以及一次到位/循序漸進之偏好，決定鋼管還是碳纖、重量段與 Flex（L, A, R, SR, S）。
- **桿頭構造矩陣**：新手且偏好循序漸進 $\to$ 鑄造厚底大凹背 (Cast Deep Cavity)；一次到位且追求看起來懂球 $\to$ 軟鐵鍛造複合凹背 (Forged Players Cavity)；練習最便宜 $\to$ 一體成型套桿組。
- **品牌地域與調性匹配**：
  - 日系 + 懂球：Mizuno, Srixon, Bridgestone
  - 日系 + 奢華：Honma, Majesty, XXIO Prime
  - 歐美 + 懂球：Titleist, Ping, TaylorMade
  - 歐美 + 奢華：PXG 旗艦系列
  - 最便宜高CP：Wilson, Tour Edge, Callaway Warbird 套桿, Cleveland
- **Google Shopping 搜尋 Query 產生器**：整合性別、手向、球桿類別、推薦品牌與桿身硬度，生成高命中率之關鍵字。
